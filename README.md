# BH.com Clothing Store — React + Vite

A responsive, India-focused clothing storefront prototype.

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally
1. Extract the ZIP file.
2. Open the extracted **BH.com-clothing-store-react** folder in VS Code.
3. Open the VS Code terminal in that folder — the folder must contain `package.json`.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included
- Responsive React + Vite storefront
- Men / Women / All collection filters
- Search and price/name sorting
- Add-to-bag, quantity controls, subtotal and remove
- Wishlist
- Demo checkout interaction
- Editorial story section and responsive mobile navigation

## Before accepting real orders
This is a front-end prototype. Connect a backend/catalogue, inventory, customer authentication, shipping/tax calculation, and a payment gateway (such as Razorpay) before production. Product images currently load from Unsplash and require internet access.
